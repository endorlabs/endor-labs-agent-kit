# How to Package Agent Source Code

This guide explains how to package your agent source code for deployment to Vertex AI Agent Engine using the provided `package_agent.py` script for publishing to Google Cloud Marketplace.

## Overview

Vertex AI Agent Engine requires the agent source code to be packaged in a specific format (tar.gz) with an entry point (`app.py`) and a `requirements.txt` file compatible with the runtime environment.

The `package_agent.py` script automates this process by:
1.  Copying the agent source code to a temporary directory.
2.  Creating a wrapper `app.py` that initializes the agent.
3.  Generating a `requirements.txt` file with the necessary dependencies.
4.  Creating a `.tar.gz` archive ready for deployment.
5.  Generating `agent_config.auto.tfvars` with the correct `agent_package_name` variable so Terraform can deploy without manual input.

## Prerequisites

-   Python 3 installed.
-   Access to the agent source code directory.

## Usage

Run the script from your agent's deployment directory where the `main.tf` file is located:

```bash
python3 package_agent.py --source <path_to_agent_source>
```

### Arguments

-   `--source`: (Required) Path to the agent source directory (e.g., `../my_agent`).
-   `--output`: (Optional) Path to the output tar.gz file. Defaults to `assets/source.tar.gz`.
-   `--package-name`: (Optional) Name of the Python package. Defaults to the basename of the source directory (e.g., `my_agent`).

### Example

To package the agent using the default settings:

```bash
python3 package_agent.py --source ../my_agent
```

This will create `assets/source.tar.gz`.

## Integration with Terraform

The `main.tf` Terraform configuration is set up to look for the packaged source at `assets/source.tar.gz`.

### Automatic Configuration (`agent_package_name`)

To avoid manual configuration errors, the `package_agent.py` script automatically generates a file named `agent_config.auto.tfvars` in the same directory. This file contains the `agent_package_name` variable, which matches the folder name you packaged (or the name you specified with `--package-name`).

**Example `agent_config.auto.tfvars`:**
```hcl
agent_package_name = "my_agent"
```

Terraform automatically loads any file ending in `.auto.tfvars`, ensuring that the `agent_package_name` variable is always set correctly for deployment.

**Important:** You must run this packaging script *before* running `terraform apply` or `terraform plan`.

## What's Included in the Package?

The script packages the following:
-   The entire agent source directory (excluding `.git`, `.venv`, `__pycache__`, etc.).
-   A generated `app.py` (entry point).
-   A generated `requirements.txt`.

The resulting archive structure looks like this:

```
source.tar.gz
└── my_agent/
    ├── agent.py
    ├── tools.py
    ├── ... (other source files)
    ├── app.py          <-- Generated
    └── requirements.txt <-- Generated
```

## Preparing for Marketplace

To deploy this agent via Google Cloud Marketplace, you need to bundle the configuration files into a zip archive.

### Files to Edit for Your Agent

Before creating the zip archive, you must edit the following files based on the specific agent you are publishing. Here is a summary of what each included file and folder does:

*   **`main.tf`**: The primary Terraform configuration that defines the infrastructure and Vertex AI Agent Engine deployment.
*   **`metadata.display.yaml`**: UI configuration for how the deployment page appears in the Google Cloud Marketplace.
*   **`metadata.yaml`**: Core technical metadata defining the Marketplace solution (versions, properties, required inputs).
*   **`outputs.tf`**: Defines the output values generated by Terraform after the deployment finishes (e.g., resource IDs).
*   **`README.md`**: The user-facing documentation for deploying and using the packaged agent.
*   **`variables.tf`**: Defines the input variables that Terraform needs to execute the deployment.
*   **`marketplace_test.tfvars`**: Provides sample values for testing the Marketplace deployment parameters.
*   **`agent_config.auto.tfvars`**: Automatically generated file containing the `agent_package_name` variable linked to your source code package. This is generated when you run the `package_agent.py` script.
*   **`assets/source.tar.gz`**: The compiled agent source code package created by the `package_agent.py` script.
*   **`modules/`**: Directory containing any local Terraform modules that the `main.tf` relies on. We are including this as a workaround to enable marketplace deployment with version 1.5.7.

You should test the terraform based deployment to your own project to verify the deployment is working well, before you start zipping it.

### Creating the Zip Archive

**Important:** You **MUST** include the `modules/` directory in this archive, as it contains the required Terraform module dependencies.

**Run this command to create the package:**

```bash
zip -r my_agent.zip \
  main.tf \
  metadata.display.yaml \
  metadata.yaml \
  outputs.tf \
  README.md \
  variables.tf \
  marketplace_test.tfvars \
  agent_config.auto.tfvars \
  assets/source.tar.gz \
  modules/
```
